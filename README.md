## Project documentation
Each project includes a problem statement, objectives, assumptions, algorithm and Mermaid flowchart, pseudocode, Python source code, test cases, and conclusion.

## Syllabus alignment
The suggested projects use topics shared so far: variables, data types, input/output, type conversion, arithmetic and relational operators, logical operators, if/elif/else, for loops, while loops, and range(). The admission merit-list project additionally uses lists, tuples, and selection sort. Confirm those topics are allowed in the complete ABL syllabus.

## Official case-study verification
The University Admission Merit List is based on the supplied activity-01.txt file. The other nine are suggested programs aligned with the syllabus topics shared in chat; they have not been verified against the faculty-provided list of 100 difficult-level case studies. Confirm the selections with the official list before final submission.

Run each program.py in VS Code and save genuine terminal screenshots in that project's output_screenshots/ folder. Expected outputs in test_cases.md are references, not screenshots. Screenshot folders contain instructions only until actual screenshots are added.
