# Case Study 01: University Admission Merit List

## Aim
To develop a Python program that checks applicants' eligibility for CSE, ECE, and MECH courses and prepares a course-wise merit list.

## Files in this folder
- `problem_statement.md`
- `objectives.md`
- `assumptions.md`
- `algorithm.md`
- `pseudocode.md`
- `program.py`
- `test_cases.md`
- `conclusion.md`

## Run the program
Open this folder in VS Code and run:

```bash
python program.py
```

## Syllabus concepts used
Input/output, variables, type conversion, relational and logical operators, if-elif-else, for loops, lists, tuples, and selection sort.
