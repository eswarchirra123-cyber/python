# Objectives

1. To accept applicant details using Python input statements.
2. To validate subject marks within the range 0 to 100.
3. To calculate the average aggregate of three subjects.
4. To apply course-wise admission cutoffs and minimum subject marks.
5. To store eligible applicants using lists and tuples.
6. To arrange eligible applicants using selection sort.
7. To display a separate merit ranking for each course.
