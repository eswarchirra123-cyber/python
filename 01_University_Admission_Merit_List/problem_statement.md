# Problem Statement

A university receives applications for admission into CSE, ECE, and MECH courses. Write a Python program to accept the number of applicants and collect each applicant's name, preferred course, and marks in Mathematics, Physics, and Chemistry.

The program must validate marks, check course-wise admission eligibility using the given aggregate cutoffs and minimum subject marks, and display eligible candidates in a course-wise merit list. Candidates must be ranked using aggregate marks, Mathematics marks, Physics marks, and candidate name as tie-breakers.
