# Program 01: Simple Calculator

## Aim
To write a Python program that performs addition, subtraction, multiplication, and division on two numbers.

## Python concepts used
- Variables and data types
- Input and output
- Type conversion using `float()`
- Arithmetic operators
- `if-elif-else` decision statements

## Files
- `problem_statement.md` — problem description
- `objectives.md` — learning objectives
- `assumptions.md` — assumptions
- `algorithm.md` — steps and flowchart
- `pseudocode.md` — pseudocode
- `program.py` — Python source code
- `test_cases.md` — sample tests
- `conclusion.md` — conclusion

## How to run
Open a terminal in this folder and run:

```bash
python program.py
```
