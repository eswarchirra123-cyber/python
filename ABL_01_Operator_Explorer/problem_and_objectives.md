# Python Operator Explorer

## Problem statement
Read two numbers and demonstrate arithmetic, comparison, logical, assignment, membership and identity operators.

## Topics covered
Unit I: arithmetic, relational, logical, assignment, membership, identity, type conversion and precedence

## Objectives
1. Understand the problem and accept valid input.
2. Apply the stated Python syllabus concepts.
3. Display clear results.

## Assumptions
- User enters valid numeric/text input as requested.
- This is a beginner-level console program.

## Conclusion
Demonstrates Unit I operators, type conversion, expressions and input/output.
