# Electricity Bill Calculator

## Aim
Write a Python program to read electricity units and calculate the bill using assumed slabs: first 100 units at Rs. 1.50 per unit, next 100 at Rs. 2.50, and units above 200 at Rs. 4.00. Reject negative units.

## Contents
Problem statement, objectives, assumptions, algorithm and flowchart, pseudocode, Python source code, test cases, and conclusion.

## Run
```bash
python program.py
```
