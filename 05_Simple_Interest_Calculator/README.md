# Simple Interest Calculator

## Aim
Read principal, annual rate and time in years. Calculate simple interest using SI = (P * R * T) / 100 and display the interest and total amount.

Problem statement, objectives, assumptions, algorithm and flowchart, pseudocode, Python source code, test cases, and conclusion.
