# Assumptions

1. The student enters numeric marks for three subjects.
2. Each subject mark must be from 0 to 100, including both limits.
3. The grade is decided using the average mark.
4. The grading scale used in this program is an assumed example and can be changed if the faculty provides a different scale:
   - 90 to 100: A
   - 80 to less than 90: B
   - 70 to less than 80: C
   - 60 to less than 70: D
   - Below 60: F
